# Road documents

現在の対応範囲は `supported_operations.md` を見る。

- `architecture.md`: authoritative / derived、generationの流れ、ownership、依存方向、局所性
- `operation_semantics.md`: 公開されている高水準operationの入力、成功結果、failure atomicity、制約
- `supported_operations.md`: UIから実際に使える操作と現在の制約
- `backlog.md`: 標準機能から外した項目と将来の範囲。目的と再開条件、却下の理由
